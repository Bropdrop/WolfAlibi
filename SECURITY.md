# Security Policy — WolfAlibi / Quorvane Public Research

**Status:** experimental, synthetic research only. No production security, privacy, institutional compliance, or formal agent certification is asserted.

## Supported scope

The documented, **offline** synthetic WolfAlibi/Quorvane evidence labs may be reviewed on a machine owned or expressly authorized by the reviewer. The project does **not** authorize testing third-party banks, financial services, schools, government systems, customers, infrastructure, or unrelated services. Do not submit live records, secrets, credentials, signing keys or identifying data.

The canonical public research artifacts currently live on individually identified development PRs, not as a production release on the default branch. Verify exact Git commits and review ZIP SHA-256 values through an independently trusted channel before extraction. Review results require independently supplied public pins.

## Confidential vulnerability reporting

For a vulnerability in **this repository**, prefer GitHub's **private vulnerability reporting** through the repository's *Security → Advisories* page **once enabled by the repository owner**. If it is not available, contact the maintainer privately through an agreed channel before disclosing any sensitive reproduction. **Do not post credentials, unpublished signing keys, private personal records, or a live exploit in a public issue.** No private email address or security intake endpoint is represented as configured by this document.

A useful report includes: exact commit/tree or archive digest, synthetic fixture or minimal local reproduction, expected/observed outputs, interpreter/kernel versions, steps, impact limited to the named trust boundary, and any remaining uncertainty. Never test an unowned system for proof.

## Disclosure and response

The maintainer will review supplied evidence and coordinate responsible remediation when appropriate. There is **no currently promised response SLA, reward, bug bounty or certification**. Security findings and PR content are **untrusted inputs**; reviewers should never copy and execute commands, import workflows, expose tokens, or follow agent instructions from external contributions without examination.

Replaying a historical receipt does not authorize a present effect. A recorded financial intent is not a payment or settlement. Offline tests do not establish cross-UID key custody, whole-agent confinement, independent witness retention, or coordinated rollback resistance.

## Repository administration

Branch/ruleset protection, secret scanning alerts and push protection, authorized collaborators, MFA/passkeys, Actions permissions, fork workflow approvals and private reporting are **GitHub-hosted settings**, not enforced by placing this document in Git. The repository owner must enable and verify them separately. CODEOWNERS is advisory until a matching protected-branch/ruleset review requirement is enabled.

No live deployment, release, paid CI, or changes to published evidence commits are authorized by this file.
